# Turcu Fineas — Personal Portfolio

Personal portfolio website for Turcu Fineas (Finimus).

🔗 **Live:** [finimus.github.io](https://finimus.github.io)

## Stack
- HTML, CSS, JavaScript — no frameworks
- [Formspree](https://formspree.io) for contact form
- Hosted on GitHub Pages

## Features
- Dark / Light mode
- EN / RO language switch
- Interactive terminal with easter eggs
- Responsive (mobile, tablet, desktop)
- SEO optimized

## Easter Eggs 🥚
There are hidden commands in the terminal. Type `help` to get started.
